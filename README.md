# MemoryVault — Digital Time Capsule Platform

MemoryVault is a full-stack digital time capsule web application where users can store memories, messages, images, and future notes securely and unlock them on a future date.

The platform is designed to preserve emotional memories digitally using a modern and responsive web interface.

---

## 🌟 Features

- 🔐 User Registration & Login
- ⏳ Future Time-Locked Capsules
- 📝 Secret Messages & Memories
- 🖼️ Media Upload Support
- 🔓 Automatic Capsule Unlocking
- 🔔 In-App Unlock Notifications
- ☁️ Cloud Deployment
- 📱 Responsive Modern UI

## 🧠 How It Works

1. User registers/login
2. User creates a future capsule
3. Capsule remains locked until unlock date
4. Scheduler checks unlock time automatically
5. Capsule unlocks when time arrives
6. User receives popup notification
7. User views unlocked memories
